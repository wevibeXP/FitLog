# FitLog

Personal fitness and nutrition tracking app. Initial Expo + React Native onboarding prototype.

## Getting started

```bash
npm install
npx expo start
```

See the source files for the current onboarding assessment prototype. Data is currently in memory only; authentication, persistence, HealthKit, Hevy, AI food recognition, and backend services are planned, not implemented.

## Safety note

Calorie and macro values are estimates, not medical advice. The assessment prototype applies conservative guardrails and withholds targets for under-18 users or selected health review flags.
